# 솜이 피아노 교실

8살 어린이를 위한 피아노 연습 웹앱이에요. 토끼 솜이가 매일 미션을 내 주고, 휴대폰 마이크로 진짜 피아노 소리를 듣고 채점해요.

**바로 열기:** https://johnjang125.github.io/somi-piano/

## 기능
- **실력 알아보기:** 처음 시작할 때 건반 찾기와 악보 읽기 실력을 재서, 알맞은 레슨부터 열어 줘요.
- **매일 연습:** 하루 XP 목표, 오늘의 미션 3개, 연속 기록, 쉬는 날을 지켜 주는 방패가 있어요.
- **레슨 10개:** 별나라 지도에서 건반 찾기, 귀로 듣기, 오선지 읽기, 노래를 차례로 배워요. 노래는 저작권이 끝난 선율만 써요.
- **맞춤 복습:** 자주 틀린 음과 노래 소절을 골라 다시 연습하게 해 줘요.
- **보상:** 보석 상점에서 솜이를 꾸미고, 스티커북을 모아요.
- **진짜 피아노 연결:** 휴대폰 마이크로 업라이트 피아노 소리를 듣고, USB 디지털 피아노는 미디로 연결해요.

## 쓰는 법
1. 휴대폰을 피아노 보면대에 세우고 위 주소를 열어요.
2. 어른 코너에서 "소리 맞추기"를 눌러요.
3. 이제 진짜 피아노로 치면 자동으로 채점돼요.

아이 이름과 연습 기록은 그 휴대폰의 브라우저에만 저장되고, 어디에도 전송되지 않아요.

## 만든 방법
설치나 빌드 없이 HTML 파일 하나로 되어 있어요. 소리 높이는 브라우저의 Web Audio로 직접 알아내요(McLeod 방식).
