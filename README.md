# 솜이 피아노 교실

8살 어린이를 위한 피아노 연습 웹앱이에요. 토끼 솜이가 매일 미션을 내 주고, 휴대폰 마이크로 진짜 피아노 소리를 듣고 채점해요.

**바로 열기:** https://johnjang125.github.io/somi-piano/

## 기능
- **실력 알아보기:** 처음 시작할 때 건반 찾기와 악보 읽기 실력을 재서, 알맞은 레슨부터 열어 줘요.
- **매일 연습:** 오늘 기분에 맞춘 미션, 하루 XP 목표, 연속 기록, 쉬는 날을 지켜 주는 방패가 있어요.
- **레슨과 놀이:** 별나라 지도의 레슨 10개, 깜짝 악보(초견), 음표 풍선, 셈여림 놀이, 연주회 모드, 내가 만든 노래.
- **곡 연습실:** 체르니·부르크뮐러·바흐·슈만·클레멘티 등 97곡. 몇 마디씩 골라 양손으로 녹음하면, 끝난 뒤 마디마다 틀린 음·빠진 음·멈칫한 곳·서두른 곳을 찾아 다음 연습 계획을 짜 줘요.
- **맞춤 복습:** 자주 틀린 음과 노래 소절을 골라 다시 연습하게 해 줘요.
- **진짜 피아노 연결:** 휴대폰 마이크로 업라이트 피아노 소리를 듣고, USB 디지털 피아노는 미디로 연결해요.

## 쓰는 법
1. 휴대폰을 피아노 보면대에 세우고 위 주소를 열어요.
2. 어른 코너에서 "소리 맞추기"를 눌러요.
3. 레슨은 진짜 피아노로 치면 바로 채점되고, 곡 연습실은 녹음이 끝난 뒤 분석해요.

아이 이름, 연습 기록, 녹음은 그 휴대폰의 브라우저 안에서만 쓰이고 어디에도 전송되지 않아요.

## 출처와 라이선스
- **악보 데이터** (`data/scores.json`): [The Mutopia Project](https://www.mutopiaproject.org)의 MIDI·LilyPond 파일을 `tools/build-scores.js`로 변환했어요. 곡마다 `license`(퍼블릭 도메인 또는 CC BY-SA)와 `source`(원본 페이지)가 들어 있어요. CC BY-SA 곡에서 만든 데이터는 같은 CC BY-SA 조건으로 배포해요.
- **녹음 받아 적기** (`bp/`): [Spotify Basic Pitch](https://github.com/spotify/basic-pitch) (Apache-2.0, `bp/LICENSE-basic-pitch.txt`)와 TensorFlow.js를 `tools/build-bp.sh`로 묶었어요.

## 만든 방법
화면은 HTML 파일 하나(`index.html`)예요. 레슨의 실시간 채점은 브라우저 Web Audio로 직접 소리 높이를 알아내고(McLeod 방식), 곡 연습실은 녹음을 Basic Pitch로 받아 적은 뒤 악보와 맞춰 봐요(동적 계획법).
